# RANDOMBUILD — автообнаружение Hunt: Showdown

В этом обновлении поиск `USER\Game.log` встроен в существующий локальный `server.js` RANDOMBUILD.
Отдельный Python-сборщик, ручное указание пути и дополнительные npm-пакеты не нужны.

## Как ищется игра

1. Проверяются стандартные записи Steam в реестре Windows (`SteamPath` / `InstallPath`).
2. Из `steamapps\libraryfolders.vdf` читаются все зарегистрированные библиотеки Steam, включая библиотеки на других дисках.
3. В каждой библиотеке проверяется `steamapps\appmanifest_594650.acf` (Hunt: Showdown).
4. Для найденной установки определяется `USER\Game.log`.
5. Если найдено несколько установок, предпочтение отдаётся существующему `Game.log` с самой свежей датой изменения.
6. Если Hunt установлен, но `Game.log` ещё не создан, сервер запоминает ожидаемый путь и ждёт, пока игра создаст файл.
7. Раз в 15 секунд библиотеки проверяются повторно — например, после подключения другого диска.

Поиск ограничен реестром Steam, его manifest-файлами, библиотеками из `libraryfolders.vdf` и стандартными папками Steam на доступных дисках. Полного рекурсивного сканирования всех файлов компьютера нет.

## Установка в проект

1. Сделай резервную копию текущего `server.js`.
2. Замени его файлом `server.js` из этого комплекта.
3. Перезапусти обычный локальный сервер RANDOMBUILD.

Используются только встроенные модули Node.js и уже используемые проектом зависимости Express/Nodemailer/Dotenv. Дополнительные `npm install` не требуются.

Обновлённый сервер продолжает обслуживать авторизацию RANDOMBUILD и дополнительно запускает поиск Hunt автоматически.

## Проверка

Открой на том же компьютере:

- `http://127.0.0.1:3001/api/game/status` — найден ли Hunt и какой Game.log отслеживается.
- `http://127.0.0.1:3001/api/game/events?after=0` — диагностические события из журнала.

Основные статусы:

- `searching` — поиск установок Steam;
- `hunt_not_found` — Hunt не найден;
- `waiting_for_game_log` — установка найдена, ожидается создание Game.log;
- `watching` — журнал найден и отслеживается;
- `in_game_session` — по записям журнала обнаружена активная игровая сессия.

Сервер привязан к `127.0.0.1`, поэтому API не открывается для других компьютеров в локальной сети.

## Ограничение текущего этапа

Обновление автоматически находит и отслеживает лог, а также обнаруживает переходы игровых состояний и экран итогов. Сам `Game.log` не содержит подтверждённых значений количества убийств и заработанных денег. Эта версия не выдумывает эти показатели и не добавляет их в прогресс контракта. Следующий этап — отдельный источник распознавания нужных значений.

## Для выпуска игрокам

Эту правку следует включить в обычное обновление RANDOMBUILD. Игрокам не нужно отдельно ставить Python, запускать вспомогательный EXE или вручную выбирать папку Hunt. Достаточно запускать обновлённый RANDOMBUILD как обычно.
